# fixtures/XX — دولة اصطناعية لاختبار العامل بلا شبكة (ر٧٣-ب-٢)

**لا ملفات مولَّدة بالمستودع.** مصدران نصيان فقط، والفهرس والحدود يُبنيان منهما لحظة `npm test` بالناشر (داخل مجلد مؤقت) بالسكربت الحقيقي — فالمثبّت دائمًا بصيغة الفهرس الحالية، وأي تغيير بـ`scripts/token-index.mjs` يظهر أثره بالاختبار فورًا.

- `XX/places.jsonl` — ٣١ مكانًا مصنوعًا (الصيغة نفسها التي يخرجها `scripts/overture-extract.py`: `id · name · addr · locality · lat · lng · common?`) حول المركز (0.5, 0.5) بأربعة أحياء وفرعَين لاسم واحد ومكان بعيد خارج نصف القطر واسم عربي باسم شائع إنجليزي. (المفردات `vocab.json` تخرج فارغة لأن عتبات الاشتقاق — ≥ ٢٠٠ عنوان · ≥ ٢٠ مكانًا للحي — أكبر من العيّنة؛ المطابقة تسلك الاحتياط العام لكلمات الشارع.)
- `XX/divisions.json` — خلية حدود واحدة `d1_1` بخمسة مضلعات متداخلة (microhood ⊂ neighborhood ⊂ locality ⊂ localadmin + حي منفصل) بالشكل الذي يكتبه `scripts/divisions-extract.py` (`[{n, t, ring:[[lng,lat],…]}]`) — مكتوبة يدويًّا لأن المصدر الحقيقي (Overture Divisions عبر DuckDB) لا يُشغَّل بالاختبار.
- `make-fixture.mjs` — `buildFixture(outDir)`: يشغّل `scripts/token-index.mjs` داخل جذر مؤقت يحاكي بنية المستودع (مساراته ثابتة نسبيًّا) ويضغط خلية الحدود. `test-index.js` يستدعيه أولًا؛ وتشغيله مباشرة بـnode يبني داخل مجلد مؤقت ويطبع مساره (لا يكتب شيئًا بالمستودع).
- `test-index.js` يحاكي `env.PLACES` (قراءة بالمدى · `head` · `put` · `list`) فوق المبنيّ ويختبر `/match` · `/match-batch` · `/area` · `noData` · تسجيل الطلب · أن القراءة بالمدى هي المسلوكة.
